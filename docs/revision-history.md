| — | 2026-08-17 | **Verified the 2026-08-16 encoder carousel on real hardware, fixed two issues found doing it.** (1) **Hero-layout redesign** — first-pass Inside/Outside/Weather pages just stretched the old quarter-grid cards to fill the screen ("blown up version of the same components," per direct feedback after seeing it live). Reworked as borderless centered compositions (matching the style Weather/About already had): temperature numbers 36pt→48pt (new `LV_FONT_MONTSERRAT_48`/`_32` enabled in `lv_conf.h`), labels 12-14pt→20pt, forecast weather icon 56×56→84×84 (redrawn from the same hand-drawn point geometry via a scale factor, not just stretched, so it stays crisp — `buildIcon()` in `lvgl_ui_s3.cpp` now takes a `scale` param; per-shape persistent point buffers were needed since `lv_line_set_points` stores a pointer, not a copy, and a naive shared scratch buffer would let one ray's points alias another's). Outdoor temp/pressure and rain are now two flex blocks separated by spacing/color instead of a bordered card. (2) **Encoder responsiveness fix** — the naive "count quarter-steps, divide by 4" quadrature decode from the initial cut was too sensitive to mechanical contact bounce: a bounced/illegal transition could eat or add a quarter-step, so real clicks sometimes needed an extra nudge to register or occasionally double-fired, reported as "sometimes ignored, sometimes delayed" and confirmed to be frequent/random rather than tied to any periodic event (ruling out the 5-minute weather-fetch HTTP block as the cause). Replaced with Ben Buxton's classic debounce-tolerant state machine (`ENCODER_STATE_TABLE` in `main.cpp`, MIT-licensed reference design) — requires the full 4-transition Gray-code sequence before ever emitting a direction; a bounced/out-of-sequence read just falls back to the start state instead of corrupting a running count. User-confirmed on hardware: rotation direction correct, responsiveness fixed ("This works much better"). |
| — | 2026-08-16 | **`esp32s3_waveshare_lcd` gains a rotary-encoder page carousel.** This board has no touch, so until now `src/lvgl_ui_s3.cpp` showed indoor/outdoor/rain/forecast all at once in a single 2x2 grid. An external KY-040 rotary encoder (Amazon ASIN B09R41C1HR) changes that: `LvglUI` now builds four full-screen pages — **Inside** (indoor temp/humidity), **Outside** (outdoor temp/pressure + rain, combined since only three content pages plus About were wanted), **Weather** (tomorrow's forecast), **About** (splash + QR to the repo, new on this board) — with the same page-indicator-dots chrome the C6 Touch LCD's swipe carousel already had (`showPage()`/`setAbout()` added to this board's `LvglUI` namespace, mirroring the C6 API). `main.cpp`'s page-cycling machinery (`PAGE_COUNT`/`g_page`/`g_lastSwipe`/`onSwipe()`/the 30s auto-return-to-page-0 timeout) was generalized from C6-only to both boards. | v2.20 | 2026-08-08 | **OTA UX: fast propagation, install-progress splash, failure tracking** (all six OTA-enabled targets).
